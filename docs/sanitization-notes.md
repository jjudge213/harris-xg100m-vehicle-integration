# Sanitization Notes

Private draft. This repository currently contains private review images and project notes only.

## Public Release Rules

Before any public release, review for:

- operational frequencies, channel names, talkgroups, or radio programming data
- radio IDs, serials, unit IDs, codeplug details, or key IDs
- encryption/key-fill references or COMSEC workflow details beyond general public-safe descriptions
- private locations, addresses, license plates, VINs, or unique vehicle identifiers
- faces, handles, comments, reflections, or other personal information
- proprietary Harris documents, programming software screenshots, or non-public pinouts
- credentials, certificates, tokens, hostnames, or private infrastructure details

## Safe Public Framing

Use:

- “vehicle speaker integration”
- “audio path and operator usability”
- “fabricated protective grille”
- “serviceable fastener layout”
- “sanitized power/RF/accessory planning”

Avoid:

- implying current access to restricted systems
- publishing proprietary Harris programming/configuration details
- showing or describing operational radio frequencies, keys, IDs, or codeplugs
- overstating the evidence as a complete documented radio install until more photos/notes are added
